# Plan

## Context

Current brainstorming/planning context or specified design\spec documents

## Your task

Create an implementation plan for $ARGUMENTS

## Instructions

Create a whole coding implementation plan as bite size tasks for a developer to implement. DRY. YAGNI.

- Assume developer has zero context for our codebase and questionable taste
- Assume skilled developer will implement, but know almost nothing about our toolset or problem domain
- Document everything they need to know: Which files to touch for each task, code, testing, docs they might need to check.
- If relevant or requested, how to test it. TDD. Assume developer dosn't know good test design very well.

Please write out this plan, in full detail, into docs/plans/
